## 本包改了什么

1. **JIT 下不装 jitless 网络垫片**：直接用 Node 原生 undici/fetch/Headers/WebSocket
   （r50 里全局 `Headers` 被 shim 替换，和 undici 混用容易让插件下载/插件请求失败）
2. **hook 超时 fail-open**：插件跑满预算不再 abort 任务创建（r50 的 smart-link 10s 超时问题）
3. **启动期插件激活挪到 HTTP 就绪之后**（异步）⇒ 冷启动少 ~480ms
4. RPC 命令失败会写 `[rpc] command failed <channel> <原因>` 到 node-output.log
5. 签名口令自动同步（DevEco 重新签名后不再报 -115）
