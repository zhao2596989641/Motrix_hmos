# r49：引擎启动快连 + JIT 就绪（探针驱动、可降级）

- 时间：2026-11-26
- 版本：`2.4.5.49` / `versionCode 240500049` / 徽章 `HarmonyOS Port r49`
- 基线：r48（冷启动已优化：host ready 2026ms）
- 产物：`Download/com.lyldeer.dshdesktop/Motrix/com.lyldeer.motrix-2.4.5.49-debug-signed-r49.hap`
  - 大小 **192,008,936 B**；MD5 `f15c072bf29894603ab18d4be98a4530`；`node scripts/verify-hap.mjs` 全部通过

## 本包改了什么

1. **引擎启动快 ~450ms**：aria2 RPC 连接重试 500ms 固定 → 20/40/80/160/250ms 前快后慢。
2. **JIT 探针驱动**：起 Node 前先问内核"能不能给可执行内存"→ 能就不带 `--jitless`（JIT+WASM），
   不能就回退（当前无 ACL，所以**本包实际仍是 jitless**，行为与 r48 一致，只是逻辑就绪）。
3. **插件运行时状态动态化**：JIT 可用时插件页不再显示"端侧不可用"横幅。
4. 受限权限构建开关（`MOTRIX_ENABLE_JIT_PERMISSION=1`，默认关）。
