## r63 做了什么

1. **把 Electron 那套 CLI 服务挪到 core**（架构边界要求 `src/server/` 不能 import `src/main/`）：
   `src/main/cli/*` → `src/core/cli/*`（cli-tool-service / package-manager / shell-environment /
   command-runner 及测试），`src/main/index.ts`、`src/main/ipc/commands.ts` 改走 `@core/cli/…`；
2. **新增 `src/server/cli-tool-runtime.ts`**：按鸿蒙用户目录构造 `CliToolService`
   （`HOME=~`、`SHELL=/usr/bin/zsh`、`PATH=~/.harmonybrew/bin:…`、`neutralDir=~`、`directInstallSupported: true`）；
3. `Queries.GetCliToolStatus` → 真实探测（发现 npm/pnpm/yarn/bun/volta + node 版本 + 是否已装）；
4. `Commands.InstallCliTool` → **真的执行 `npm install -g @motrix/cli@latest`**
   （与 Electron 同一套实现，含超时 300s、输出脱敏、失败原因归类）；
5. 宿主注入 `MOTRIX_CLI_DETECT=1` / `MOTRIX_USER_HOME`；
6. 删掉 r61 的只读 `cli-tool-detect.ts`（已被完整服务取代）。

本机自测（同一台设备、同一 harmonybrew 环境）：
`phase=ready`、`capability=direct`、`packageManager=npm`、`nodeVersion=26.12.0`，
npm / pnpm 标记为可用，`@motrix/cli` 未安装 —— 卡片应显示「安装」按钮。
