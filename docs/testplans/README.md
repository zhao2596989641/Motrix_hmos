## 历史

- **r38**：稳定基线（托盘面板三行任务行 + 固定排序），HAP MD5 `a8eb917104e54aa39865c4dfb8019982`。
- **r43**：❌ 「失败 1.5s 快速重试」压满 ArkWeb 6 条连接 → "无法连接服务器"，已整体回档到 r38。
- **r39/r40**：入口收敛 + 减体积（回档后丢弃，r46 重新落地了体积部分）。
- 更早轮次（r1–r42）的验证项见 [../CHANGELOG.md](../CHANGELOG.md) 与 [../FEATURE-MATRIX.md](../FEATURE-MATRIX.md)。

## 约定

1. **一轮一包**：每轮只叠一批改动，出包 → 真机验证 → 通过后再叠下一轮。
2. 每份清单必须能"照着点"，并写清**回退到哪一版**（Download 里保留上一版 HAP）。
3. 异常时优先导出 `logs/`（`scripts/gather-logs.sh` 一条命令拉全部诊断文件）。
