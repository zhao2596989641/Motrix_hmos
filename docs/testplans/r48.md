## 本包改了什么（只动启动链路，不动下载/插件逻辑）

1. **不再等引擎就绪**：宿主只等 HTTP 入口应答（healthz 200 或 503 都算通），
   UI 先加载，引擎显示「启动中 → 就绪」（这是**新的预期行为**，不是卡住）。
2. **spawn 诊断挪到 ready 后 20s**（以前它在关键路径上白吃 ~200ms）。
3. **healthz 轮询 300ms → 60ms**。
4. **并行**：窗口创建时就启动 Node；Web 组件第一帧就 `about:blank` 预热 ArkWeb 内核。
5. 服务端新增 `boot:` 耗时日志（见下）。

3. 发我 `logs/boot-stage.json`：预期阶段变成
   `env_ready → preflight → shims_ready → server_imported → http_listening → operator_token → session_cookie → ready`，

4. 发我 `logs/node-output.log`（r48 起含启动细分），重点看这些行（每行带 `elapsedMs`）：
