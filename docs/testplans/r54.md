## 改了什么（都是观感/入口，不动下载逻辑）

1. **关于页：检查更新整块隐藏**
   - 上游「检查更新」区域 + 左下角「自动检查更新」开关，在鸿蒙壳里**整块不渲染**，
     也不再向 server 查询更新状态（避免白跑 RPC、避免点出 500）。
   - 依据：`isHarmonyShell()`（壳注入 `__MOTRIX_PLATFORM__`）。
2. **鸿蒙版本徽章与 `2.4.5` 中轴对齐**
   - 徽章原来和版本号一起按**文字基线**排（`items-baseline`），药丸的上下内边距让它看起来偏下。
   - 现在版本号 + 徽章包进一个 `items-center` 的 flex 行：徽章盒子中线对齐 `2.4.5` 行盒中线。
3. **托盘图标改为华为规范的黑白单色自适应**
   - 官方 `StatusBarIcon`：`white` = 深色壁纸用**纯白**、`black` = 浅色壁纸用**纯黑**，
     建议 24vp×24vp。
   - 以前白/黑都读彩色 `app.media.startIcon`，深色壁纸上边缘发灰。
   - 现在用 `rawfile/tray_white.svg`、`rawfile/tray_black.svg`（形状取自上游 `extra/tray/tray.svg`，
     24×24 画布、内容 20×20 居中、单色填充）；rawfile 读不到时退回彩色图标兜底。
4. **开屏改为 Clash 风格：只有居中 logo**
   - 删掉加载转圈（`LoadingProgress`）、「Motrix」标题与「正在启动内核 / 等待引擎 / 正在载入界面」等文案，
     只留 112vp 居中应用图标（深/浅色各自底色不变）。
   - 失败页保持原样（错误原因 + 日志尾巴 + 重试按钮）。
5. **开机自启：改成「跳转系统设置」按钮（Clash 做法）**
   - 上游确实**有开关**（`settings.general.launchAtStartup`，非 Linux 平台显示 Switch），
     但 HarmonyOS 只给查询接口（`autoStartupManager.getAutoStartupStatusForSelf` /
     `isAutoStartupSupported`），**三方应用无法自行开启**。
   - 所以关于页那行提示**删掉**，改成 设置 → 通用 里的「登录时启动」行：
     · 说明文字：「HarmonyOS 不允许应用自行开启…请在 设置 → 应用和元服务 → 应用启动管理 中手动添加」
     · 当前状态：已开启 / 未开启 / 设备不支持（壳查询后注入 `__MOTRIX_PLATFORM__.autoStartup`）
     · 右侧按钮「打开系统设置」→ `motrix-action://autostart` → 壳依次尝试
       应用详情页 → 应用与元服务 → 设置首页（鸿蒙没有公开「应用启动管理」的 uri）
   - 壳查完状态会推 `motrix-platform-change` 事件，设置页据此即时刷新状态。
