# r52：补上官方内置插件（修"插件市场装不上"的真因）

- 时间：2026-11-26
- 版本：`2.4.5.52` / `versionCode 240500052` / 徽章 `HarmonyOS Port r52`
- 基线：r51
- 产物：`Download/com.lyldeer.dshdesktop/Motrix/com.lyldeer.motrix-2.4.5.52-debug-signed-r52.hap`
  - 大小 **192,034,727 B**；MD5 `57f16dd4e39313a8e5aa551f7cb61cee`；`verify-hap` 全绿；包内已含 `resfile/app/builtin-plugins/`

## 背景（真机反馈结论）

你装不上的两个插件是**官方内置插件**：
- `motrix.filename-template`（Motrix 文件名模板，按模板重命名下载完成的文件）
- `motrix.url-resolver`（URL 解析器）

它们的 hook id 是 official builtin，上游**禁止从市场安装**（错误 `plugin.install.official_builtin_hook`），
必须由应用随包提供。我们的构建此前从未跑 `fetch-builtins`，所以它们显示"未安装"且安装必失败。

## 本包改了什么

1. 新增 `scripts/fetch-builtins.mjs`：原生 fetch 下载 → sha256+Ed25519 校验 → 解包到
   `vendor/motrix/dist/builtin-plugins/`（缓存 `build/builtin-artifacts/`）
2. 构建时 `builtin-plugins/` 随 HAP 分发；registry 按 builtin 扫描 ⇒ 显示已安装
3. 其余与 r51 相同（插件健壮化、原生 undici、hook 超时 fail-open、启动激活挪后、签名口令同步）

## 验证清单

### A. 装包
1. 覆盖安装成功；关于页 `2.4.5.52` + 徽章 `r52`

### B. 内置插件（本轮重点）
1. 插件页里 **Motrix 文件名模板 / URL 解析器** 应显示为**已安装**（不再有"安装"按钮/未安装标签）
2. 下载一个文件 → 完成后文件名应按默认模板重命名（filename-template 生效）
3. 若仍显示"未安装"：发我 `logs/node-output.log` 里 `plugin:` 开头的行 +
   `logs/spawn-probe.json`（可能 registry 扫描 builtin 目录失败）

### C. 插件报错区（历史噪声）
- 你会看到一批 `plugin.runtime.worker_start_failed: WebAssembly is not defined`，
  **这些是 r49 及以前的旧日志**（每小时一条定时激活失败），r50 JIT 后不再新增；
  UI 日志查看器只是把历史记录都显示出来了，不是这次的。
- `notify capability is not available in this runtime`（debug）：插件想发系统通知，
  server 形态下上游只给 Electron 实现 ⇒ 目前是空操作，不影响功能。
