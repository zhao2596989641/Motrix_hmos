## 本包改了什么（一句话：把"每个窗口面各自读引擎状态"改成"全应用一份"）

1. **单例 store**：`useEngineDisplayStatus` 改为模块级 store，全局一份快照 + 超时 1 条在飞请求
   - 切页/重挂载**立刻**拿到上次确认的状态，不再从 `starting` 起步
   - 曾经确认过 `ready` 的，后续读失败**也保持 `ready`**（原来卡住的直接原因）
2. **失败退避** 5s→10s→20s→30s（带抖动），从未确认过引擎时 5s 兜底；**没有任何毫秒级快速重试**
3. 事件流 `EngineStateChanged` 仍是主通道（即时、权威）；轮询降级为兜底（连接正常 60s、断线 10s）
4. `GetSettings` 只在首次/设置变更时读（原来是每次挂载都读一遍）
5. **新增只读网络诊断**（仅鸿蒙壳、每类最多 12 行，落在 `arkts-diag.log` 的 `web-console:` 里）：
   - `[motrix] query burst: N reads in flight before <channel>` ← 发起时已有 ≥5 条读在飞
   - `[motrix] slow query <channel> <ms>` ← 单条读 ≥3s
   - `[motrix] engine status read failed: <原因>` ← 引擎状态读失败（每次失败连续最多 2 行）
