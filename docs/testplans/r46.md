## 本包改了什么

1. **HAP 减 11.5MB**：`resfile/app/bin/{aria2c,motrix-finalize-fs}` 不再随包。
   端侧真正执行的是 `entry/libs/arm64-v8a/*.bin`（安装时解压到 `<bundle>/libs/arm64/`），
   resfile 里那份是重复的。构建脚本改为签 `build/bin` 的源文件再铺进 libs。
2. **启动阶段细分**：`boot-stage.json` 的 `stages[]` 新增
   `server_imported` / `server_healthy` / `operator_token` / `session_cookie` / `platform_restore`。
3. **Dock 进度条**：原来"先记已推送、再推送"，启动早期 `1020210010`（快捷栏图标还没出现）
   一失败就再也不刷新；改为成功才记，失败下一 tick 重试、连续 5 次才放弃。
4. 恢复 `scripts/gather-logs.sh`。
