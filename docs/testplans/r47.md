## 本包改了什么

1. **版本号方案落地**：以后每轮只改 `AppScope/app.json5` 两处；出包后自动核对。
2. **插件安全降级（修真 bug）**：真机日志实证「装了插件 → HTTP 任务直接失败」
   （`plugin chain aborted: … WebAssembly is not defined`）。现在无 WebAssembly 时：
   插件不激活、hook 失败一律 fail-open（不再 abort 任务链）；插件页顶部有黄色横幅说明。
3. **W^X 探针（本轮最重要）**：起 Node 前在 app 进程里试 `mmap(RW)→mprotect(RX)` 与 `mmap(RWX)`，
   写 `<filesDir>/wx-probe.json`（hdc 拉得到）。结果决定插件路线：
   - `"execmemAllowed": true` → 下一版尝试去掉 `--jitless`，上游 QuickJS 沙箱原样可用 + 整体变快
   - `false` → 换 `node:vm` 沙箱（只自己用，可接受）
4. **`scripts/verify-hap.mjs`**：签名/原生件/`.bin` 后缀/main.mjs 一致性/版本号/渲染层产物一次校验。
